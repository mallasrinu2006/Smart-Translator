# 🌐 Smart Translator

A simple, modern, and user-friendly **Smart Translator Web Application** that allows users to translate text between multiple languages with a beautiful animated interface.

## ✨ Features

* 🌐 Translate text between multiple languages
* 🔄 Swap source and target languages
* ✍️ Real-time character counting
* 📋 Copy translated text
* 🔊 Listen to the translated text using text-to-speech
* 🗑️ Clear input and output text
* 🚀 Simple and fast translation interface
* 🎨 Modern animated UI
* 📱 Responsive design for different screen sizes
* ⚡ Easy-to-use interface

## 🌍 Supported Languages

The application currently supports:

* 🇬🇧 English
* 🇮🇳 Telugu
* 🇮🇳 Hindi
* 🇮🇳 Tamil
* 🇮🇳 Kannada
* 🇫🇷 French
* 🇩🇪 German
* 🇪🇸 Spanish

## 🛠️ Technologies Used

* **HTML5** – Creates the structure of the application
* **CSS3** – Provides styling, animations, and responsive design
* **JavaScript** – Handles translation, buttons, language switching, copy, clear, and text-to-speech functionality
* **Translation API** – Used to convert text from one language to another

## 💡 How It Works

1. Select the **source language**.
2. Select the **target language**.
3. Enter your text in the input box.
4. Click **🚀 Translate Now**.
5. The translated text appears in the output box.
6. Use **📋 Copy** to copy the translation.
7. Use **🔊 Speak** to hear the translation.
8. Use **⇄** to swap the languages.
9. Use **🗑️ Clear** to clear the text.
